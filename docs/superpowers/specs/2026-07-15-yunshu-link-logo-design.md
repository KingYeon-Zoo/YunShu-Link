# 云枢 YunShu Link Logo 设计规格

**日期：** 2026-07-15  
**状态：** 已确认，待生成

## 1. 品牌定位

云枢（YunShu Link）是面向 ESP32 智能语音硬件的 AI 后端与设备管理平台。产品打通实时语音识别、语言模型推理、语音合成、工具调用和设备控制链路，并通过 Web 与移动控制台管理用户、设备、智能体和模型配置。

Logo 应表达“智能连接中枢”，而不是有声读物、单一语音工具或机器人助手。

## 2. 核心概念

- 以一个清晰的中心节点表现“枢”。
- 三条流线汇入中心后向外延伸，隐喻 ASR → LLM → TTS 的实时语音管线。
- 流线整体形成抽象语音波形和 `Y` 形结构，强化 YunShu 的英文首字母记忆点。
- 外围节点表达 ESP32 终端、云端 AI、IoT 工具和管理平台之间的连接。
- 图形保持简洁，在 32×32 px 的导航与应用图标场景下仍应可辨识。

## 3. 视觉语言

- 风格：现代、简洁、科技感、矢量友好、几何结构清楚。
- 主色：钴蓝 `#3375FD`，与现有 Web 设计 Token 保持一致。
- 辅色：少量蓝紫色，用于增强数据流与智能感。
- 背景：最终文件使用透明背景。
- 形态：圆润但不过度卡通，适配现代 SaaS 管理后台。
- 禁止元素：书本、机器人、传统麦克风、具象云朵、复杂电路板、3D 吉祥物、摄影质感、水印。

## 4. 品牌文字

- 中文主标必须准确写作：`云枢`
- 英文副标必须准确写作：`YunShu Link`
- 中文为主要视觉层级，英文作为较小的辅助标识。
- 字体采用现代无衬线风格，字形清晰、稳重，与图标的圆润几何结构协调。

## 5. 交付物

1. 透明背景横版组合 Logo：左侧图标，右侧中文“云枢”，中文下方为英文“YunShu Link”。
2. 透明背景方形纯图标：不含文字，用于侧边栏、头像、应用图标和 favicon 源文件。
3. AI 生图源图与完成透明化处理后的 PNG 文件均保存在项目资源目录，不覆盖现有 `xiaozhi-logo.png`。

## 6. 验收标准

- 品牌文字无错字、漏字和多余字符。
- 图标在浅色与深色背景上均保持清晰轮廓。
- 透明 PNG 四角的 Alpha 值为 0，无明显色键残边。
- 图标缩小到 32×32 px 后，中心枢纽与主要连接流线仍可辨认。
- 完整横版 Logo 适合登录页与 README，方形图标适合控制台导航和应用入口。
